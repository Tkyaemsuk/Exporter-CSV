## 📤 XLSX-EXPORT — Budibase Component Plugin

> Plugin สำหรับส่งออกข้อมูลจาก Budibase อย่างเป็นระบบ พร้อม Visual Column Designer การจัดรูปแบบภาษาไทย และการล็อกดีไซน์ไว้ใน Component Settings

**Version:** `1.10.7`  
**Compatibility:** Budibase `v3.4.1`  
**Runtime:** Svelte `3`  
**License:** MIT

---

## 📌 ภาพรวม

`XLSX-EXPORT` เป็น Custom Component Plugin สำหรับ Budibase ที่ช่วยส่งออกข้อมูลจาก **Table, View, Query และ Data Provider** ไปยังไฟล์หลายรูปแบบ โดยผู้พัฒนาสามารถกำหนดชื่อ ลำดับ สี ความกว้าง การจัดตำแหน่ง และรูปแบบข้อมูลของแต่ละคอลัมน์ผ่าน Visual Designer ได้

รุ่น v1.10.7 รองรับการอ่านข้อมูลแบบแบ่งหน้าจาก Data Provider จนครบตาม `Max rows` และกำหนด footer ระดับหน้าเอกสาร โดย “วันที่เริ่มใช้งาน” และ “รหัสเอกสาร” จะแสดงคู่กันทุกหน้าของไฟล์ที่พิมพ์หรือส่งออก

รุ่นนี้ยังคงใช้ snapshot จาก Designer ฝังสีที่ตรงเงื่อนไขลงในเซลล์ XLSX จริง และรองรับชื่อสี CSS เช่น `yellow` ใน JSON

ดีไซน์คอลัมน์และส่วนหัวเอกสารถูกจัดเก็บร่วมกันในช่อง `Locked design data` ของ Component จึงติดไปกับ App Definition และไม่สูญหายเมื่อเปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์

> Plugin ไม่ใช้ `localStorage` และไม่ต้องสร้าง Config Table เพิ่มเติม

## ✨ คุณสมบัติเด่น

### 🔌 การเชื่อมต่อข้อมูล

- รองรับ Table และ View
- รองรับ Budibase Query
- รองรับ Data Provider
- ตั้งค่า Sort column และ Sort order ได้
- กำหนด Page size และจำนวนแถวสูงสุดสำหรับการส่งออกได้
- อ่านข้อมูลต่อเนื่องทุกหน้าของ Data Provider จนถึงหน้าสุดท้ายหรือถึงจำนวน `Max rows`

### 📁 รูปแบบไฟล์

- CSV (`.csv`)
- Excel Workbook (`.xlsx`)
- Excel XML (`.xls`)
- HTML (`.html`)
- PDF (`.pdf`)
- JSON (`.json`)

### 🎨 Column Designer

- เปิดหรือปิดแต่ละคอลัมน์
- เปลี่ยนชื่อหัวคอลัมน์
- เลือก Field ต้นทาง
- กำหนดชนิดข้อมูลอัตโนมัติ ข้อความ ตัวเลข หรือวันที่
- กำหนดรูปแบบวันที่และ Time zone รายคอลัมน์
- กำหนดจำนวนตำแหน่งทศนิยม
- จัดตำแหน่งข้อความซ้าย กึ่งกลาง หรือขวา
- กำหนดความกว้างคอลัมน์
- กำหนดสีพื้นหลังและสีข้อความของหัวตารางหรือข้อมูล
- กำหนดสีพื้นหลังและสีข้อความตามค่าของเซลล์ด้วย Conditional Formatting
- รองรับเงื่อนไข เท่ากับ ไม่เท่ากับ มากกว่า น้อยกว่า มีข้อความ ขึ้นต้น ลงท้าย ค่าว่าง และไม่ว่าง
- ใช้กฎแรกที่ตรงเงื่อนไขและรองรับได้สูงสุด 20 กฎต่อคอลัมน์
- เรียงลำดับ ทำสำเนา และลบคอลัมน์
- มีปุ่ม `ออกแบบหัวเอกสาร` อยู่ใน Visual Designer เดียวกัน

### 🇹🇭 ภาษาและวันที่

- รองรับภาษาไทยและภาษาอังกฤษ
- รองรับ UTF-8 BOM สำหรับ CSV ภาษาไทย
- รองรับเวลา Thailand UTC+07:00 และ UTC
- รองรับปีพุทธศักราช (พ.ศ.)
- รองรับชื่อเดือนภาษาไทย
- ตรวจจับค่า ISO Date และ Date field อัตโนมัติ

### 🖼️ รูปแบบเอกสาร

- เพิ่มส่วนหัวเอกสารได้หลายแถว
- Merge คอลัมน์ในส่วนหัวด้วย `colspan`
- กำหนดสีพื้นหลัง สีข้อความ การจัดตำแหน่ง ตัวหนา ตัวเอียง และขนาดตัวอักษรราย Cell
- ตั้งค่าสีหัวตารางและสีข้อความ
- กำหนดตัวอักษรและขนาดตัวอักษร
- เปิดใช้แถวสลับสีได้
- กำหนดเส้นขอบตาราง
- รองรับลายน้ำจาก URL หรือ Base64 Data URI
- รองรับส่วนท้ายเอกสาร วันที่เริ่มใช้งาน และรหัสเอกสาร
- ตั้งชื่อไฟล์และเพิ่มวันเวลาต่อท้ายชื่อไฟล์ได้

> **หมายเหตุ:** CSV และ JSON เป็นรูปแบบข้อมูลที่ไม่รองรับสีหรือรูปแบบเซลล์ ควรใช้ XLSX, XLS, HTML หรือ PDF เมื่อต้องการเก็บรูปแบบตาราง

## 🚀 การติดตั้ง Plugin ใน Budibase

1. เปิดโฟลเดอร์ `release`
2. เลือกไฟล์ `xlsx-export-1.10.7.tar.gz`
3. เปิด Budibase Portal
4. ไปที่ **Settings → Plugins**
5. เลือก **Add plugin → File Upload**
6. อัปโหลดไฟล์ Plugin
7. Refresh หน้า App Builder
8. เพิ่ม Component ชื่อ `XLSX-EXPORT` ลงในหน้าจอ

## ⚙️ การใช้งานเบื้องต้น

1. เลือก Component `XLSX-EXPORT`
2. ที่หัวข้อ `DATA SOURCE` เลือก Source type
3. เลือก Table, View, Query หรือ Data Provider
4. ตั้งชื่อไฟล์และรูปแบบไฟล์ที่หัวข้อ `FILE`
5. กำหนดภาษา วันที่ สี และรูปแบบตารางตามต้องการ
6. Preview ข้อมูลก่อนส่งออก
7. กดปุ่ม `ส่งออกไฟล์`

## 🧾 การสร้าง Document Header ผ่าน Visual Designer

1. กดปุ่ม `ออกแบบคอลัมน์` บน Component
2. ในหน้าต่าง Designer กด `ออกแบบหัวเอกสาร`
3. กด `เพิ่มแถว` และ `เพิ่มช่อง` ตามต้องการ
4. ใส่ข้อความและกำหนดจำนวนคอลัมน์ที่ต้องการ Merge
5. เลือกสีพื้นหลัง สีข้อความ การจัดวาง ตัวหนา ตัวเอียง ขนาดตัวอักษร และเส้นขอบ
6. ตรวจสอบหัวเอกสารใน Live Preview แล้วกด `ใช้ดีไซน์และคัดลอกค่าล็อก`
7. วางค่าที่คัดลอกไว้ใน `Locked design data` แล้วกด `Publish`

Document Header จะทำงานอัตโนมัติเมื่อพบ Header Rows ไม่ต้องเปิดสวิตช์แยก และไม่รองรับการใส่รูปภาพหรือโลโก้ในส่วนหัว

ไม่จำเป็นต้องเขียนหรือแก้ไข Header Rows JSON ด้วยตนเอง และระบบยังอ่านค่ารูปแบบเก่าจาก v1.5.0 ได้เพื่อป้องกันดีไซน์เดิมสูญหาย

> รูปภาพรองรับใน XLSX, HTML และ PDF ส่วนแถวข้อความ การ Merge และสีรองรับใน XLSX, XLS, HTML และ PDF

## 🎯 การกำหนดสีตามเงื่อนไข

1. เปิด `ออกแบบคอลัมน์`
2. กด `กำหนดเงื่อนไขสี`
3. เลือกคอลัมน์แล้วกด `เพิ่มเงื่อนไข`
4. เลือกตัวดำเนินการและใส่ค่าที่ต้องการเปรียบเทียบ
5. เลือกสีพื้นหลังและสีข้อความ เช่น `ค่าเท่ากับ 1 → พื้นหลังสีแดง`
6. กด `ใช้เงื่อนไข` และตรวจสอบผลใน Preview
7. กด `คัดลอกเพื่อล็อกดีไซน์` แล้ววางใน `Locked design data` ก่อน Publish

Conditional Formatting มีผลกับ Preview และไฟล์ XLSX, XLS, HTML และ PDF ส่วน CSV และ JSON จะส่งออกเฉพาะข้อมูลตามข้อจำกัดของรูปแบบไฟล์

ระบบไม่รัน JavaScript จากผู้ใช้โดยตรง จึงลดความเสี่ยงจากโค้ดอันตรายและทำให้กฎทำงานเหมือนกันในทุกเบราว์เซอร์

## 🔒 การล็อก Column และ Document Header Design

Budibase v3.4.1 ไม่อนุญาตให้ Runtime Plugin แก้ไข Component Settings ของตัวเองโดยตรง ขั้นตอนการบันทึกดีไซน์จึงออกแบบให้ชัดเจนและปลอดภัยดังนี้

1. เปิด Visual Designer
2. ปรับแต่งคอลัมน์และส่วนหัวเอกสารให้เรียบร้อย
3. กด `คัดลอกเพื่อล็อกดีไซน์` หรือ `ใช้ดีไซน์และคัดลอกค่าล็อก`
4. กลับไปที่ Component Settings
5. เปิดหัวข้อ `COLUMNS`
6. วางค่าลงในช่อง `Locked design data`
7. กด `Publish`

หลัง Publish ดีไซน์จะถูกเก็บกับ Component และใช้งานได้เหมือนกันทุกเบราว์เซอร์
